## Test Flow (Single Prompt)

**Input:** `"Write 3 Facebook posts for the Hilux truck launch campaign targeting automotive buyers in Douala. Include hashtags and a call-to-action."`

### Step 1: Prompt Reception (0-50ms)
- JSON-RPC `start_mission` with prompt
- Creates entry in `missions` table
- **Validation:** Check `tasks.db` for mission record

### Step 2: Prompt Reformulation (50-200ms)
- Calls `PromptReformulator.reformulate()`
- Generates tool_chain with:
  - Step 1: `WRITE_TECHNICAL_REPORT` (CONTENT_GENERATED|||)
  - Step 2: `WRITE_EXECUTIVE_REPORT`
- **Validation:** Technical report contains `Reformulated Tool Chain` JSON

### Step 3: Context Injection (200-500ms)
- First implication calls `sysInspect(mode="skeleton")`
- Structural skeletons appended to state summary
- **Validation:** State summary contains `Structural Skeletons` section

### Step 4: Tool Execution (500-5000ms)
- LLM calls `WRITE_TECHNICAL_REPORT`
- LLM calls `WRITE_EXECUTIVE_REPORT`
- Decisions recorded in `decisions` table
- Observations recorded in `observations` table
- **Validation:** `decisions` table has 2 rows, `observations` has 2 rows

### Step 5: Artifact Verification (5000-5500ms)
- Technical report file exists
- Executive summary file exists
- Task state file has steps populated
- **Exit code:** 0 = SUCCESS, non-zero = FAILURE

## Timing Instrumentation

Wrap each phase with `const start = Date.now()` and log `duration: Date.now() - start`

## Pass Criteria

1. Mission created: 1 row in `missions` table
2. Tasks created: 2 rows in `tasks` table
3. Decisions recorded: 2+ rows in `decisions` table
4. Technical report: Contains reformulated tool chain JSON
5. Executive report: Contains mission summary
6. Task state: Has `steps` array with observations
7. Exit code: 0

## Risk Mitigation

- **Missing API keys:** Verify `.env` contains valid `KORE_API_POOL_PATH`
- **Path issues:** Workspace `/home/elo/workspace` must exist and be writable
